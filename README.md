# Me salió la R

Método y bot de Telegram para que adultos practiquen la R múltiple (rr), paso a paso y con una práctica corta por día.

- `docs/`: el método (v1.3), su revisión y el relevamiento de fuentes.
- `bot/`: el bot de Telegram (prototipo). Ver `bot/README.md`.
- `app/`: contenido de las lecciones.
- `site/`: la landing, que se publica con GitHub Pages.

No reemplaza a un fonoaudiólogo.
